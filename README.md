# alen_maincrafts_internship_task-1

## Project Overview

- This repository contains the files and documentation for a static portfolio website hosted using AWS S3 and CloudFront as part of Task 1 of the Maincrafts Cloud Computing &amp; DevOps Internship Program
- The project involved developing and deploying a static portfolio website using AWS S3 and AWS CloudFront.

## Technologies Used

- HTML
- CSS
- AWS S3
- AWS CloudFront
- GitHub

## Features

- Static website hosting using Amazon S3
- Global content delivery using Amazon CloudFront
- HTTPS support through CloudFront
- Public access configuration using S3 Bucket Policies

## Hosted URLs

### S3 Static Website Endpoint (HTTP)

http://alen-cloud-portfolio.s3-website.ap-south-1.amazonaws.com

### CloudFront Distribution URL (HTTPS)

## Repository Contents

- `index.html` – Main webpage
- `style.css` – Stylesheet for the website
- `Task_1_shots/` – Screenshots demonstrating the deployment process and final output

## Deployment Summary

1. Created an Amazon S3 bucket.
2. Uploaded the website files.
3. Enabled Static Website Hosting.
4. Configured bucket permissions and policies.
5. Created an Amazon CloudFront distribution.
6. Enabled HTTPS delivery through CloudFront.
7. Verified successful deployment.
